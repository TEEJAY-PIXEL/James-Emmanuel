# James Portfolio

A single-page Next.js portfolio with a clean white, black and grey design.

## Run locally

```bash
cd portfolio-site
npm install
npm run dev
```

Open http://localhost:3000.

## Profile image

Place James's portrait at:

```
portfolio-site/public/images/james-profile.webp
```

The homepage uses this path for the centered portrait in the main profile card.

## Customize

- Update the headline and introduction in `app/page.tsx`.
- Update services in the `services` and `capabilities` arrays in `app/page.tsx`.
- Update colors, spacing and responsive styling in `app/globals.css`.
- Add a real email address to the contact link before publishing.
